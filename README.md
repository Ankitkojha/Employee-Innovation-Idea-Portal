Employee Innovation & Idea Voting Portal
 
Project Overview
 
The Employee Innovation & Idea Voting Portal is a Microsoft Power Platform application that allows employees to submit innovative ideas and vote on ideas submitted by other employees.
 
Managers can review submitted ideas and approve or reject them.
 
Technologies Used
 
- Microsoft Power Apps – Canvas App
- Microsoft Power Apps – Model-driven App
- Microsoft Dataverse
- Power Automate
 
Main Features
 
Employee Features
 
- Submit new innovation ideas.
- Explore submitted ideas.
- Vote for ideas.
- Track idea status.
 
Manager Features
 
- View submitted ideas.
- Approve or reject ideas.
- Manage innovation submissions.
- Monitor idea voting activity.
 
Application Components
 
1. Canvas App – Employee-facing application.
2. Model-driven App – Manager-facing application.
3. Dataverse – Central database.
4. Power Automate – Workflow automation and notifications.
 
Repository Structure
 
- Solution: Exported Power Platform solution ZIP.
- Screenshots: Application screenshots.
- Documentation: Project documentation.
 
How to Import
 
1. Open Power Apps Maker Portal.
2. Select the target environment.
3. Navigate to Solutions.
4. Select Import Solution.
5. Upload the solution ZIP.
6. Configure connection references and environment variables.
7. Complete the import.
8. Configure connections and permissions.
9. Publish and test the applications.
